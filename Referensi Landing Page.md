# Referensi Landing Page — Game Edukasi Anak

Diadaptasi dari analisis situs Setara (setara.fyi). Ambil pola yang bermanfaat, buang yang tidak relevan.

---

## ✅ Yang Diambil (Bermanfaat)

### 1. Pola "Demo dulu → Masuk"
Dua tombol terpisah di header. Orang tua bisa mencoba game sebelum membeli.
- **Demo gratis** = 1 level / 1 game dibuka
- **Masuk (login)** = unlock full per grup grade
- Nyambung langsung dengan strategi *account-based access* (anti-pembajakan)

### 2. Countdown Launch
Timer hitung mundur untuk membangun hype sebelum rilis.
- Cocok untuk momentum kampanye TikTok / Reels
- Contoh: *"Grup SD Kelas 1 rilis dalam X hari"*

### 3. Kartu Game / Karakter (Visual)
Layout ringkas: gambar + judul + deskripsi singkat.
- Dipakai untuk menampilkan tiap game / maskot per grup
- Mudah di-scan mata, ramah mobile

### 4. Copy Santai & Jelas
Satu kalimat *value proposition* yang gampang dibaca.
- Tone diarahkan ke **ramah anak & orang tua**

### 5. FAQ
Menjawab keraguan pembeli:
- "Kenapa harus bayar?"
- "Aman nggak buat anak?"
- "Bisa dimainkan di HP?"

---

## ❌ Yang Dibuang (Tidak Relevan)

- **Verifikasi email kampus & eksklusivitas** → target kita orang tua/anak, bukan komunitas tertutup
- **Konsep match / dating** → tidak berlaku sama sekali
- **Palet warna terlalu kalem** → game anak butuh warna lebih cerah & kontras tinggi
- **Segmentasi berdasar universitas** → ganti jadi segmentasi **grade level** (TK, SD Kelas 1, dst)

## 🎯 Terjemahan ke Konteks Game Anak

| Elemen Setara | Versi Game Anak |
|---|---|
| Demo / Masuk | Coba gratis / Login unlock per grup |
| Countdown "17 Agustus" | Countdown rilis grup grade baru |
| Kartu profil orang | Kartu game / maskot per grup |
| Logo kampus (social proof) | Badge "dipakai di X sekolah" / testimoni ortu |
| Verifikasi email kampus | (dibuang) |
| Warna pastel hangat | Warna cerah, kontras, playful |
