# Engine Game (Fase 2)

Folder ini akan berisi engine reusable:

- `core/` — game loop, scene manager, state
- `ui/` — tombol besar, popup bintang, progress bar
- `audio/` — manajer narasi TTS + SFX (lazy load)
- `templates/` — 6 template tipe game (lihat CLAUDE.md)

Prinsip: menambah game baru = menulis config JSON + aset, bukan kode baru.
